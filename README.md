# ZephyCubeBorder v1.1.1

ZephyCube Border for Minecraft Bedrock Edition. Square world border, keeps the world spawn loaded, ender pearls cannot pass barriers.

## Install

Download `ZephyCubeBorder-v1.1.1.mcpack` from the Releases page and open it, or copy the `ZephyCubeBorder` folder into your world's `behavior_packs` folder and add its `uuid` and `version` (from `manifest.json`) to the world's `world_behavior_packs.json`. Needs `@minecraft/server` 2.8.0.
